# Combat

Combat is a core game system in which players engage in combat with monsters (Player vs Monster) or with other players (Player vs Player).

Player vs Monster (PvM) combat is the main method of character progression, granting players experience, gold and items.

## Your Tools

`load_player_stats` - For player-specific requests. Use when you need to load the player's stats for combat-based calculations.
